# 라이트 제출 재시도 계약이 실제 동작과 달랐다

- 작성일: 2026-09-07
- 관련: 이슈 #70

## 무엇이 잘못됐나

라이트 제출 API가 이미 제출한 참여자의 재시도에 200과 기존 완료 시각을 반환하는데, OpenAPI에는 409 충돌로 문서화돼 있었다.

## 원인

- **설계적 원인**: 재시도 성공 동작을 응답 계약에 명시하지 않고 일반적인 충돌 응답을 남겼다.
- **코드적 원인**: `apps/backend/main.py`의 submit 데코레이터가 도달하지 않는 409 응답을 선언했다.

## 해결

409 문서를 제거하고 200 설명에 최초 제출과 재제출 모두 저장된 `completedAt`을 반환한다고 명시했다.

## 재발 방지

OpenAPI 응답 코드와 200 설명을 검사하는 통합 테스트를 추가하고 스냅샷·프론트 타입을 재생성했다.
