# <짧은 제목>

- 작성일: YYYY-MM-DD
- 관련: 이슈 #, PR #, 커밋 <sha>

## 무엇이 잘못됐나

증상. 어떻게 발견했는지(테스트 실패, CI, 프로덕션 스모크, 리뷰 등).

## 원인

- **설계적 원인**: 요구사항/계약/아키텍처 판단이 잘못됐던 부분. (해당 없으면 생략)
- **코드적 원인**: 구현 버그의 구체적 지점(파일:줄). (해당 없으면 생략)

## 해결

무엇을 바꿔서 고쳤는지. 왜 그 방법을 택했는지(대안이 있었다면 왜 기각했는지).

## 재발 방지

테스트/린트/문서로 어떻게 잠갔는지. 앞으로 비슷한 상황에서 무엇을 먼저 의심해야 하는지.
