# DeepPlanForm 금액 편집기의 원시 입력 상태 누락

- 작성일: 2026-09-07
- 관련: 이슈 #119, PR 미생성, 커밋 없음

## 무엇이 잘못됐나

계획 화면에서 금액을 모두 지우면 상태 선택이 `모름`으로 바뀌고 입력창이 비활성화됐어요. 빈 금액에서 `정확히 앎`을 고르면 값이 입력되지 않았는데도 선택이 `0원`으로 바뀌었어요.

## 원인

- **설계적 원인**: 화면 선택 상태를 사용자가 고른 값이 아니라 커밋된 `Amount` 값에서 매 렌더링마다 파생했어요. 입력 중인 빈 문자열을 별도 상태로 표현하지 않았어요.
- **코드적 원인**: `widgets/deep-plan-form/ui/DeepPlanForm.tsx`의 `AmountEditor`가 빈 문자열에 `unknown`을 즉시 emit했고, known 상태를 만들 때 이전 값이 없으면 `0`을 주입했어요.

## 해결

`AmountField`와 같은 로컬 상호작용 상태를 `AmountEditor`에 적용했어요. 원시 문자열과 선택 상태를 로컬에 보존하고, 파싱할 수 없는 빈 값에서는 `onChange`를 호출하지 않으며, known 상태의 빈 입력에는 `금액을 입력해 주세요.` 오류를 표시해 사용자가 값을 채우도록 했어요.

## 재발 방지

금액 컨트롤을 수정할 때는 커밋된 서버 값과 입력 중 원시 문자열을 하나의 상태로 합치지 않는지 먼저 확인해야 해요. 관련 동작은 기존 계획 화면 테스트와 최종 전체 게이트로 확인해요.
