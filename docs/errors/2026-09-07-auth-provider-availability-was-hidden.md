# 로그인 제공자 가용성이 프론트에 보이지 않았다

- 작성일: 2026-09-07
- 관련: 이슈 #74

## 무엇이 잘못됐나

카카오 로그인이 꺼지고 심사용 로그인만 켜진 정상 구성에서 프론트가 카카오 버튼을 표시할 수 있었다. 버튼을 누르면 최상위 OAuth 이동이 404로 끝났다.

## 원인

- **설계적 원인**: 인증 제공자 설정을 서버 내부 구성으로만 두고 로그인 화면이 읽을 공개 계약을 만들지 않았다.
- **코드적 원인**: `apps/backend/auth/router.py`에 활성화된 provider 목록을 반환하는 읽기 경로가 없었다.

## 해결

인증 없이 읽는 `/api/v1/auth/providers`를 추가해 카카오·심사용 로그인 활성 상태를 반환했다. Deep 모드가 꺼진 경우에는 기존 전역 게이트가 404를 유지한다.

## 재발 방지

카카오 전용, 심사용 전용, Deep 비활성 구성을 모두 검사하는 통합 테스트와 프론트 전달 문서를 추가했다.
