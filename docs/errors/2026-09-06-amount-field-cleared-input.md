# 금액 필드를 지운 뒤 다시 입력할 수 없었던 문제

- 작성일: 2026-09-06
- 관련: 이슈 #81, PR/커밋 없음 (코디네이터 통합 예정)

## 무엇이 잘못됐나

AmountField에서 알려진 금액을 모두 지우면 상태를 `unknown`으로 바꾸면서 입력 컨트롤도 비활성화되어, 새 금액을 다시 입력하려면 화면을 벗어나야 했다. AmountField 상호작용 테스트에서 값을 지운 뒤 새 금액을 입력하는 흐름을 검증하는 중 발견했다.

## 원인

- **설계적 원인**: 상태 불변식(`known`이면 값이 있어야 함)을 지키는 것과 입력 가능 여부를 같은 조건으로 묶었다.
- **코드적 원인**: `AmountField.tsx`에서 입력 `disabled`를 `value.status !== "known"`에 연결했다.

## 해결

입력은 컨트롤 자체가 비활성화된 경우에만 막고, 빈 입력 이벤트가 발생하면 `{ status: "unknown", value: null }`을 내보내도록 분리했다. 이후 사용자가 다시 숫자를 입력하면 컨트롤이 `{ status: "known", value }`를 내보내므로 불변식은 유지하면서 편집 흐름을 이어갈 수 있다. 상태 선택 버튼은 계속 세 상태 전환을 명시적으로 제공한다.

## 재발 방지

AmountField 테스트가 알려진 금액 삭제, 미정 상태에서 알려진 상태 전환, 삭제 후 재입력까지 고정한다. 앞으로 값의 유효성 조건과 편집 가능성 조건을 하나의 `disabled` 분기로 합치기 전에, 해당 상태에서 사용자가 복구할 수 있는 입력 경로가 남는지 먼저 확인한다.
