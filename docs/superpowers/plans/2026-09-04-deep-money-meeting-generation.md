# 우리 돈의 기준회의 — C단계 실행 계획

**목표:** 승인된 A/B 위에 실제 호출 가능한 어댑터와 안전한 생성 경로를 구현하되, 로컬 모의 검증만 수행한다.
**방식:** 순차 구현, 테스트 우선, 최소 회귀 검증. 유료 호출·운영 설정·커밋·푸시·배포 제외.

## 설계 결정

- 공식 Python OpenAI SDK / Responses / 구조화 출력. `gpt-5.4-mini-2026-03-17`, reasoning none, 출력 최대 800토큰, 총 20초, SDK 재시도 없음, store=false.
- `DEEP_MEETING_AI_ENABLED=false` 기본값. 키 등록만으로 켜지지 않는다. 품질 평가 후 별도 활성화한다.
- 실전송 안내를 포함하는 consent-v2만 신규 저장/호출에 사용한다. 기존 v1 동의는 준비 완료로 인정하지 않으며 본인 화면에서는 재동의가 필요한 상태로 반환한다.
- GET explanation은 무료 조회/템플릿만, POST explanation만 생성 가능. 양측 최신 동의·핵심 재무 공유·접근 권한이 필요하다.
- 외부 전송은 A단계 허용 목록 근거와 구조화된 추가 답변만. 계정/세션/초대 코드, 자유 입력, 합의 원문은 보내지 않는다.
- 캐시 키: 현재 report/round/plan, 추가 답변·동의 revision, 합의 식별자·버전·확인 상태, 근거, 프롬프트/모델 버전. 양측 조회 키는 동일하다.
- 검증된 출력은 세션 meeting 안에 저장한다. 답변/동의 변경은 출력을 지우며 round/탈퇴/TTL도 기존 세션 수명에 따른다. 읽기/전송 직전/저장 전후 최신 컨텍스트를 재검사한다.
- 별도 시도 원장에는 원문 없이 세션 ID/해시/기한/상태만 저장한다. `_id` 유일성으로 같은 컨텍스트는 최대 한 번 시도한다. 프로세스 중단·시간 초과처럼 과금 여부가 모호하면 잠금을 재획득하지 않고 템플릿으로 끝낸다. 오래 걸린 완료 결과도 폐기한다.
- UTC 날짜별 전역 예산을 Mongo CAS로 선예약한다. 기본 $0.25/일, 최대 20회/일. 요청 JSON UTF-8 크기 제한과 입력 여유분·최대 출력에 대한 보수적 예약액을 적용한다. 실패에도 환급/자동 재시도하지 않는다. 실제 사용량이 예약 가정을 초과하면 당일 추가 호출을 닫는다. 대시보드 알림이나 선불 잔액을 엄밀한 서버 한도로 취급하지 않는다.
- 장애·거절·잘림·형식/근거 검증 실패는 서버 템플릿으로 대체한다. 원시 오류/미검증 문장은 사용자·저장소에 남기지 않는다. 캐시 적중·쟁점 없음·비활성은 호출하지 않는다.
- 이미 전송 중인 요청은 철회로 회수할 수 없다. 별도 합의 컬렉션과 세션 사이에는 트랜잭션이 없으므로 저장 후에도 재검사하고, 매 조회에서 캐시 키를 대조한다. 구조 검증은 의미적 정확성 검증을 대신하지 않는다.

## 구현 순서

- [x] 설정/공식 SDK 어댑터·템플릿의 실패 테스트 → 구현
- [x] 동의 v2·컨텍스트 키·시도/예산 원장·생성/조회 API 실패 테스트 → 구현
- [x] 동시 호출·동의 철회·합의 변경·늦은 완료·한도/장애 회귀 검증
- [x] OpenAPI/프론트 타입/운영 안내·인계 갱신, 최종 읽기 전용 리뷰

결과: C단계 36개 포함 관련 179개 테스트 통과. 실 Mongo/유료 모델/화면/배포 검증은 다음 단계다.

- [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs)
