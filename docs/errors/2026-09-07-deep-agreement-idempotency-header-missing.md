# 합의안 생성 멱등성 키 누락

- 작성일: 2026-09-07
- 관련: 이슈 #72, 커밋 8f05fb2

## 무엇이 잘못됐나

합의안 생성 API가 `Idempotency-Key` 헤더를 필수로 요구하도록 바뀐 뒤, 프론트엔드 호출부는 헤더 없이 요청하고 있었다. 최신 develop 병합 직후 TypeScript OpenAPI 검사에서 발견됐다.

## 원인

- **코드적 원인**: `apps/frontend/src/entities/deep-agreement/api/deep-agreement.ts`가 새 API 계약의 필수 헤더를 요청 파라미터에 전달하지 않았다.

## 해결

합의안 생성 함수가 멱등성 키를 인자로 받아 헤더로 전송하게 했고, 화면에서는 같은 내용의 재시도에는 같은 키를 재사용하고 내용이 바뀌면 새 키를 생성하도록 연결했다.

## 재발 방지

API 단위 테스트에서 헤더 전송을 검증한다. OpenAPI 계약 변경을 병합한 뒤에는 생성 요청을 사용하는 프론트 호출부의 타입 검사와 단위 테스트를 함께 실행한다.
