# 하단 완료·AI 연결 백엔드 인계

2026-09-05, `codex/deep-money-meeting` 로컬 작업. 코드 변경과 실제 화면/운영 반영을 구분한다.

## 구현 범위

- `POST /api/v1/deep/v3/sessions/{id}/meeting/complete`: 하단 최종 행동 한 번으로 본인 추가 답변과 개별 선택한 공유/AI 동의를 원자 저장하고 해설로 연결.
- 본인 revision은 한 번 증가한다. 같은 최신 답변/동의를 다시 보내면 기존 기록과 해설 캐시를 유지한다.
  stale 요청은 409이며 철회된 동의를 복원하지 않는다. 생성 단계에서 저장된 본인 revision을 재검사한다.
- 양측이 준비되기 전에는 waiting만 반환한다. 미동의여도 기존 `/result`를 이용할 수 있다.
  마지막 동의자의 완료 요청에서 생성하고 먼저 완료한 사람은 GET으로 확인한다. GET은 절대 유료 생성하지 않는다.
- 영속 평가 누적 예약 원장과 감사된 이전 사용분 설정. 일일 한도와 함께 적용한다.
  새 완료 경로는 누적 설정 전 유료 호출을 막지만 저장·기본 해설은 유지한다.
- 질문 helpText를 쉬운 말로 변경했다. 이미 밝힌 조정 최대 금액을 다시 묻지 않고,
  양측 최대 금액으로도 예산에 모자라면 예산 조정, 범위가 충분하면 그 범위 안의 새 제안,
  한쪽만 미정이면 그쪽 조정 가능 여부를 질문한다. 가능 범위를 합의/지급 능력으로 판정하지 않는다.
- 프롬프트 v4로 캐시 버전을 분리한다. 형식/근거 검증은 유지하며 실제 모델 품질 승인은 아니다.
- OpenAPI 두 스냅샷과 프론트 생성 타입을 갱신했다. UI 구성/디자인은 변경하지 않았다.

## 프론트 전달

[API 가이드](../deep-meeting-api.md)의 서비스용 권장 흐름과 `/complete` 예제를 따른다.
질문은 `GET /me`의 text/helpText/options를 사용한다. 서버 동의 안내와 별도 미선택 선택을 하단에 모은다.
AI 선택에 대한 명시적 완료 행동 외에 비용 확인/모델 선택/AI 요청 버튼을 추가할 필요가 없다.
대기 시 기존 공동 결과를 유지한다. 화면이 보이는 동안에만 5초 간격·최대 60초 GET 조회를 권장한다.
오류/응답 유실 뒤에는 현재 본인 저장 상태와 해설을 GET으로 확인한다. POST/동의를 자동 재전송하지 않는다.

## 검증

- 없는 완료 API에서 404 실패, 없는 누적 예산 필드에서 실패, 기존 질문 분기의 다섯 실패를 확인 후 구현.
- 같은 답변 재완료로 revision/캐시가 바뀌는 실패를 확인 후 no-op 처리.
- 백엔드 전체 591 passed / 23 skipped / 기존 경고 11개. 실Mongo 등 별도 실행 조건의 테스트는 실행하지 않았다.
- 변경 모듈 Ruff, mypy 15개 파일, 프론트 TypeScript 검사 통과.
- OpenAPI 연속 두 번 생성 동일성 확인. 신규 실제 외부 API 호출 없음.
- 별도 읽기 전용 코드 리뷰에서 추가 P1/P2 지적 없음. 검토자 환경의 pytest 실행 불가와 별개로
  위 테스트는 주 작업 폴더의 기존 가상환경에서 실행한 결과다. `git diff --check`도 통과했다.

## 남은 범위와 운영 경계

1. 실제 공동 리포트의 주거 일정·월 적자·목표·수용 조건을 질문/결정 항목에 연결한다.
2. 이를 외부 AI가 다루도록 하려면 최소 근거 투영·동의 범위/버전·가상 사례 평가를 별도 구현한다.
3. 기존 기준표의 제안/예외/재확인/양측 확인을 결과 흐름에 연결하고 프론트에서 검증한다.
4. [누적 예산 운영 설정](../deep-meeting-operations.md)에 따라 이전 사용/예약액과 국외이전 등의 실제 운영 근거를 확인한다.

현재 동의 v2와 AI 데이터 범위는 월 분담용 그대로다. 동의 화면 배치로 법적 의무를 모두 충족했다고 보장하지 않는다.
프론트 하단 화면/대기 조회, 카카오/운영 변수 변경, 유료 호출, 커밋·푸시·develop PR/병합·배포는 수행하지 않았다.
이전 로컬 Deep UI/Kakao 변경은 그대로 보존했다. 이번 새 구현과 합칠 범위는 커밋 전 별도로 선택한다.
