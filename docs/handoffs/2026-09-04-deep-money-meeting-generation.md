# 우리 돈의 기준회의 — C단계 인계

2026-09-04. `codex/deep-money-meeting`, 기준 develop `a62efe9`. 이전 A/B 변경을 보존했다.
전체 A/B/C는 로컬 미커밋 상태다. 푸시·배포하지 않았다.

## 구현

- 공식 OpenAI SDK 의존성 추가, GPT-5.4 mini 스냅샷/Responses/JSON 스키마/표준 처리 등급 연결.
- 기본 비활성. 키만 등록되어 있어도 호출하지 않는다. 무료 GET과 명시 POST `/meeting/explanation`을 구분한다.
- 동의 v2로 갱신. 이전 v1 비전송 동의를 실전송에 재사용하지 않는다.
- 허용 목록 근거 + 구조화 추가 답변만 전송하며 상대 기대 방향을 expectingRole 기준으로 맞췄다.
- 보고서/답변/동의/합의/프롬프트/모델 기준 공유 캐시, Mongo 유일 시도 원장, UTC 일별 CAS 비용 선예약.
- 같은 컨텍스트에 대한 자동 재시도/잠금 재획득 없음. 애매한 중단·실패·한도 부족도 기본 해설로 종료한다.
- 현재 동의/만료/탈퇴/근거 변경을 전송 직전 및 저장 전후 재검사한다. 철회 시 해설 캐시를 지우고 탈퇴 시 시도 원장을 삭제한다.
- 공급자 거절·타임아웃·429/5xx·잘림·잘못된 JSON/응답 껍데기·근거 오류를 기본 해설로 대체한다.
- 로컬 테스트 실행기는 실제 API 키와 AI 활성화 설정을 상속하지 않도록 추가 차단했다.
- OpenAPI 세 사본/프론트 생성 타입 갱신, 프론트 화면 변경 없음.

## 검증

- 새 API/예산 모듈이 없어서 실패하는 테스트부터 작성했다. SDK는 httpx.MockTransport로만 검증했다.
- C단계 새 테스트 36개; A/B·기존 v3/OpenAPI·세션·라이프사이클·심사용 로그인 포함 **179 passed, 5 warnings**.
- Ruff 통과, mypy deep 및 관련 새 테스트 **52 source files** 통과, 프론트 typecheck 통과.
- OpenAPI 두 번 연속 생성 일치, 세 사본 SHA256 일치, 프론트 타입 재생성 완료.
- 리뷰에서 비정상 공급자 응답 처리 및 탈퇴 직후 시도 삽입 경쟁을 발견했다. 각각 실패 재현 후 수정하고 리뷰 재확인에서 잔여 문제 없음.
- 동시성은 기존 MemoryDatabase로 production repository 조건을 검사했다. 실제 Mongo 경쟁 검증을 대신하지 않는다.
- 코드 형식·근거 ID 검증이 AI 문장의 의미적 진실/안전성을 보장하지 않는다. 실모델 품질 평가는 하지 않았다.
